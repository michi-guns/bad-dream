# Templates

- [Proposal](proposal.md): a reviewable unaccepted change.
- [Knowledge note](knowledge-note.md): flexible metadata and reasoning.
- [Decision](decision.md): accepted scope and provenance when it exists.
- [Horror study](horror-study.md): event, reaction, interpretation and experiment.
- [Technology experiment](technology-experiment.md): question, baseline and measurements.
- [Task execution brief](task-execution-brief.md): how, where and with whom a task is worked.
- [Handoff](handoff.md): concise durable resume context.

Templates contain prompts, never fabricated evidence or acceptance.
